FAQ

Questions fréquentes.

Comment GiftFinder choisit les cadeaux ? +

GiftFinder utilise tes réponses pour comprendre la personne, son budget, ses goûts et l'occasion afin de sélectionner les recommandations les plus pertinentes.

Les produits sont-ils réels ? +

Lorsque la recherche produit est activée, les informations produits proviennent de la source produit connectée.

Combien de recherches puis-je faire gratuitement ? +

Le compte gratuit dispose d'une recherche gratuite par jour selon le fonctionnement actuel du service.

Que se passe-t-il après ma recherche ? +

GiftFinder affiche les recommandations correspondant aux critères renseignés.

Que comprend Premium ? +

Premium donne accès aux recherches illimitées pendant la période active de l'abonnement.

Les packs de recherches sont-ils cumulables ? +

Les crédits achetés sont ajoutés au compte utilisateur lorsqu'un paiement est confirmé.

Mes favoris sont-ils conservés ? +

Oui. Les favoris sont conservés localement dans le navigateur.

Comment fonctionne le paiement ? +

Les paiements sont traités via Stripe lorsque le paiement est activé sur le serveur.
